# Mullet run Reel: footage credits and post notes

Built by `build-mullet-run-reel.sh` (1080x1920, 28s, H.264/AAC). The audio bed
is the real surf sound from the Apollo Beach clip. Add music in the Instagram
app so the track is licensed through Instagram.

The mullet are striped mullet (*Mugil cephalus*), the same species that runs
the Florida coast each fall, but this clip was filmed in the Red Sea. No
openly licensed underwater footage of the Florida run itself turned up on
Commons, Pexels, Pixabay or Mixkit. Swap in your own or a licensed Florida
clip when you have one.

Because the mullet clip is CC BY-SA 4.0, the finished Reel is shared under
CC BY-SA 4.0 as well. The end card carries the credits, and the caption below
repeats them.
